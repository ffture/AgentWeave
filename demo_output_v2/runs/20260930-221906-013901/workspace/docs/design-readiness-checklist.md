# 设计就绪检查清单

用于在启动系统方案设计（T2）前逐项确认。

## 检查项

- [ ] I1 系统目标已明确
- [ ] I2 核心使用场景已明确
- [ ] I3 功能范围已明确且含优先级
- [ ] I4 质量需求已明确（性能/安全/可用性/可维护性）
- [ ] I5 技术约束已明确或已授权自行选型
- [ ] I6 数据约束已明确
- [ ] I7 验收标准已明确
- [ ] I8 交付形态已明确

## 判定

- 全部勾选：设计就绪，可启动 T2 正式设计。
- 存在未勾选项：设计阻塞，需先向用户追问对应信息。
